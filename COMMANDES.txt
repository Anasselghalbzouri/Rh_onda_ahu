========================================================
   RH ONDA - Commandes utiles
========================================================

--------------------------------------------------------
LANCER L'APPLICATION SANS ADMIN (mode developpement)
--------------------------------------------------------
Ouvrir DEUX terminaux dans le dossier du projet.

Terminal 1 (backend) :
    cd backend
    php artisan serve

Terminal 2 (frontend) :
    cd frontend
    npm run dev

Puis ouvrir l'URL affichee par le terminal 2 (ex. http://localhost:5173).
Aucun droit administrateur requis.


--------------------------------------------------------
REPARER LE PACKAGE PORTABLE (erreur PHP 8.4 vs 8.3)
--------------------------------------------------------
Regenerer vendor compatible avec le PHP 8.3 embarque :

    composer install --working-dir=livraison-portable/backend --no-dev --optimize-autoloader --ignore-platform-reqs


--------------------------------------------------------
CONSTRUIRE LE PACKAGE PORTABLE (livrable client)
--------------------------------------------------------
    powershell -ExecutionPolicy Bypass -File build-portable.ps1


--------------------------------------------------------
DOCKER (necessite Docker Desktop - admin pour l'installer)
--------------------------------------------------------
    docker compose up --build
    -> ouvrir http://localhost:8080
